# 토큰

토큰은 원시 토큰(`src/design-system/tokens/primitives.css`)과 의미 토큰(`semantic.css`) 두 단계다. 원시 토큰은 값만 말하는 이름(`--size-38`, `--duration-160`)이고, 의미 토큰은 쓰임새를 말하는 범용 역할 이름(`--surface`, `--bar-height`)이다. 의미 토큰 값은 모두 원시 토큰을 가리키고, 테마는 색 의미 토큰의 값만 바꾼다. 컴포넌트와 소비자는 의미 토큰만 쓴다.

Tailwind에는 의미 토큰 중 색·반경·이징을 `@theme inline`으로 노출한다(ADR 0003). 기본 색 팔레트(`bg-red-500` 등)는 꺼져 있다. 치수·모션 시간·타이포 스케일은 `h-(--bar-height)`, `duration-(--motion-fast)`처럼 변수 유틸리티로 쓴다.

테마는 `<html data-theme="dark|light">`로 고르며, 속성이 없으면 어두운 테마다. 툴바의 테마 메뉴로 바꾸면 아래 견본과 값이 함께 바뀐다.

## 색

견본 값은 `<html>`의 계산된 CSS 변수를 런타임에 읽는다. 유틸리티 이름은 `bg-`·`text-`·`border-` 뒤에 토큰 이름을 붙인다(예: `bg-surface-panel`, `text-prose`).
