# motion-poster — 모션그래픽 포스터 시안

A/B/C 시안을 대체하는 단일 시안. hero 전체를 무대로 쓰는 키네틱 컷아웃 포스터.

- 실행: `index.html` 열기 (`../vendor/gsap.min.js`, `../vendor/ScrollTrigger.min.js`, `../assets/article-hero.png` 사용)
- 색: 배경 #FAF8F5 · 코랄 #E9AC9F · 차콜 #242424 · 보조 #66615D
- 글꼴: Arial Black / Helvetica Neue 계열 초굵은 산세리프

## 구조

hero 안에 같은 크기의 레이어 3장이 겹쳐 있고, 각 레이어에 같은 위치의 타이틀 사본이 있다. 마스크가 지나가면 타이틀 색만 바뀌고 위치는 고정된다.

1. 종이 레이어: 크림 바탕, 코랄 컷아웃(SVG path morph), 차콜 조각, 코랄 위에서만 보이는 크림색 초대형 `sc`
2. 차콜 레이어: `clip-path: polygon` 마스크, 띠 마스크 안에서 올라오는 코랄 `WON`
3. 코랄 레이어: SVG `clipPath`(objectBoundingBox) 유기적 마스크, 크림색 `blog`

## 12초 시퀀스

| 시간 | 장면 |
| --- | --- |
| 0–2.4s | 타이틀은 첫 프레임부터 고정. 코랄 컷아웃이 기울며 변형되고, `sc`가 엇갈려 이동 |
| 2.4–5.0s | 차콜 마스크가 사선으로 열림 → `WON` stagger로 올라옴 → 화면 전체가 차콜 |
| 5.0–8.6s | 코랄 종이가 왼쪽 아래에서 들어와 확장 → 수축, `blog`/`WON`이 서로 반대 방향으로 이동 |
| 8.6–12s | 차콜이 오른쪽으로 빠지고 코랄 종이는 오른쪽 위로 사라짐. 컷아웃이 처음 구도로 돌아오며 반복 |

장면 전환 사이에도 배경 글자의 수평 이동과 종이의 기울기가 12초 주기로 이어진다. 반복 끝에서는 시작 위치로 돌아와 정지 구간 없이 연결된다. 이 움직임도 일시정지와 reduced-motion 설정을 따른다.

마스크는 들어온 방향의 반대편으로 빠져나가고, 레이어를 다시 맞추는 작업은 가려진 동안에만 일어나기 때문에 역재생처럼 보이지 않는다.

## 동작

- 하단 컨트롤: 일시정지/재생, 처음부터 보기. 일시정지하면 타임라인과 parallax가 함께 멈추고, 재개할 때 현재 위치에서 이어서 재생한다.
- hero가 화면 밖에 있거나 탭이 숨겨지면 재생을 멈춘다. 돌아왔을 때 사용자가 일시정지한 상태였다면 그대로 유지한다.
- 스크롤: hero 장면이 축소되며 물러나고 경력/글이 나타난다(pin 없음).
- reduced-motion: 사선 차콜 + 코랄 종이 정적 구도로 고정하고, 모든 내용을 바로 표시한다.
- 글 카드를 클릭하면 요약 미리보기 dialog가 열린다(시안 표시 포함).
