# 010 블로그 리뉴얼 — 모션 프로토타입

한 페이지에서 `?variant=A|B|C`로 세 안을 비교하는 시안이다. 실제 블로그 코드(`src/`)와는 분리되어 있다.

## 실행

```sh
cd specs/010-blog-renewal/prototype
python3 -m http.server 4381 --bind 127.0.0.1
```

- http://127.0.0.1:4381/?variant=A
- http://127.0.0.1:4381/?variant=B
- http://127.0.0.1:4381/?variant=C

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 구조(header / hero / 소개 / 글 / footer), 발췌 패널, 비교 컨트롤 |
| `styles.css` | 색·타이포·레이아웃, 시안별 hero 배치, B 슬랫 3D 구조 |
| `app.js` | 시안 선택, 세 가지 hero 장면, ScrollTrigger 연출, 컨트롤 |
| `vendor/` | GSAP 3.13.0, ScrollTrigger (로컬 파일, CDN 없음) |
| `assets/article-hero.png` | 글 썸네일 |

## 세 안

- **A 날의 직물** — Canvas + `gsap.ticker`. 제목 위 영역에 세로 실을 촘촘히 짜고, 위아래 끝을 고정한 채 파동을 흘린다. 실 굵기와 농도가 옆으로 흘러 곡면처럼 보이고, 코랄 띠가 실 사이를 지나간다. 포인터 주변의 실은 옆으로 밀려 휘어진다. 제목 영역에는 그리지 않는다.
- **B 뒤집히는 글자** — CSS 3D(`perspective`, `preserve-3d`) + GSAP timeline `rotationX`. 제목을 가로 슬랫(데스크톱 12, 모바일 8)으로 나누고, 각 슬랫 앞면(차콜 글자)과 뒷면(코랄 면)에 같은 제목 전체를 넣어 `top: k × -100%`로 맞춘다. 정렬 → 코랄로 뒤집힘 → 교대 줄무늬 → 다시 정렬을 반복하며, 매 단계에서 제목이 읽히도록 정지 구간을 둔다. 포인터 근처 슬랫은 별도 요소(`.slat`)에서 기울어져 timeline 회전(`.slat-inner`)과 충돌하지 않는다. 스크린리더는 `sr-only` 제목만 한 번 읽는다.
- **C 끊기지 않는 한 줄** — Canvas 2장 + `gsap.ticker`. 사인파 두 개로 움직이는 중심선에 비틀림 각을 더해 리본의 앞/뒷면과 명암을 실시간으로 계산한다. 폭이 숨 쉬듯 변하고, 포인터 쪽으로 곡선이 당겨지며 비틀림이 빨라진다. 일부 구간은 제목 앞 캔버스로 지나가며 그림자를 떨어뜨려 깊이를 만든다. 주변을 가는 실 세 가닥이 따라간다.

## 공통 동작

- **스크롤**: hero 그래픽(`.hero-art`)은 작아지고 흐려지며 물러나고, 제목은 바깥 래퍼(`.hero-copy`)만 움직여 B의 슬랫 변형과 겹치지 않는다. 소개·경력·글은 ScrollTrigger로 등장한다.
- **hero가 화면 밖**이면 ticker/timeline을 멈춘다.
- **prefers-reduced-motion: reduce**: 자동 모션·스크롤 연출 없음. A/C는 정지된 한 장면, B는 일반 텍스트 제목. 모든 내용이 즉시 보인다.
- **반응형**: `gsap.matchMedia()`가 모션 허용 여부와 모바일(≤640px) 조건이 바뀔 때 장면을 정리(ticker 제거, 리스너 해제, ResizeObserver 해제, DOM 복구)한 뒤 다시 만든다. 캔버스는 ResizeObserver로 새 치수를 반영하고 DPR은 최대 2.
- **모바일**: 실 개수·리본 분할 수를 줄이고 그림자 블러를 생략한다.

## 비교 컨트롤 (프로토타입 전용)

- 하단 고정 바: A/B/C 링크, 현재 안 이름, 모션 일시정지/재생(ticker와 timeline 모두 제어).
- 키보드 ←/→로 안 전환. 입력 필드·편집 영역에 포커스가 있거나 패널이 열려 있으면 무시한다.
- 선택은 URL 쿼리에 남으므로 새로고침해도 유지된다. 전환은 페이지를 다시 불러온다.

## 범위 밖

- 전체 글 페이지. 글 카드는 요약 패널(`<dialog>`)만 연다.
- 웹폰트. 제목은 시스템의 `Arial Black`(없으면 Helvetica/Arial 굵은 체)을 쓴다.
