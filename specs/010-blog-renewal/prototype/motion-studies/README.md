# Motion Studies — scwon’s blog 히어로 5안

장면을 차례로 넘기는 방식을 버린 프로토타입입니다. 각 시안은 첫 프레임부터 하나의 완성된 구성이고, 여러 요소가 끊김 없이 동시에 움직입니다. 장면 전환, 팔레트 교체, 순서대로 등장하는 연출은 없습니다.

## 실행

```sh
cd specs/010-blog-renewal/prototype
python3 -m http.server 8000
# http://localhost:8000/motion-studies/?variant=A
```

빌드나 설치, 네트워크 의존성이 없습니다. `../vendor/gsap.min.js`(ticker, matchMedia)와 `../assets/article-hero.png`만 씁니다. 그림은 모두 Canvas2D로 그립니다.

## 다섯 시안

| 키 | 이름 | 구성 방식 | 한 줄 차별점 |
|---|---|---|---|
| A | Warp & Weft | 맞물리는 구조 (직조) | 코랄 날실과 잉크 씨실이 위아래로 엮이고, 서로 반대로 변하는 굵기 파동이 직조 무늬 자체를 변형합니다. |
| B | Engraved Lens | 밀도 (해칭/판화) | 가로 해칭선의 굵기만으로 간섭 물결을 새기고, 천천히 도는 렌즈 안에서 밀도가 코랄로 반전됩니다. |
| C | Type Case | 타이포그래피 구성 | 활자 칸마다 들어간 s·c·w·o·n이 줄마다 다른 속도로 흐르고, 대각선 파동에 따라 글자가 커지며 잘리고, 칸 채움도 함께 차오릅니다. |
| D | Louvre Light | 건축적 실루엣 + 사영 | 아치 창의 회전 루버와, 같은 루버를 바닥에 사영한 빛 그림자가 같은 각도로 함께 움직입니다. |
| E | Contour Island | 지도/음각 공간 | 흐르는 높이장을 등고선과 색면으로 그리고, 제목 자리는 비워 둔 분지로 남겨 해안선이 제목을 감쌉니다. |

레이아웃도 시안마다 다릅니다. A는 좌우 분할(모바일에서는 위아래), B는 전면 그림 위 하단 한 줄 제목, C는 상단 제목 아래 활자 띠, D는 잉크 바탕 위 우측 아치 창(모바일에서는 위쪽 창), E는 전면 지도 한가운데 제목입니다. 모바일에서는 각 시안의 그림 크기와 위치를 다시 잡습니다(`w < 700` 분기와 CSS `@media (max-width: 760px)`).

### 메커니즘 메모
- **A**: 날실과 씨실을 `Path2D`로 만듭니다. 굵기는 길이 방향으로 변합니다. 씨실 → 날실(종이색 틈 stroke) 순서로 그린 뒤, `(i+j)`가 짝수인 교차점만 셀 단위로 clip해서 씨실을 다시 덮어 평직을 만듭니다. 날실과 씨실은 서로 다른 방향으로 천천히 미끄러집니다.
- **B**: 가로선마다 위·아래 가장자리를 샘플링해 다각형으로 채웁니다. 굵기는 이동하는 두 근원점의 간섭(cos)으로 정합니다. 렌즈는 두 원 clip의 교집합이고, 안쪽에서는 반 칸 어긋난 코랄 선이 굵기를 반전합니다. 제목 사각형 주변에서는 선이 사라집니다.
- **C**: 칸 격자의 줄 오프셋, 글자 크기(칸 clip으로 잘림), 아래에서 차오르는 코랄과 위에서 내려오는 잉크(그 안의 글자는 종이색으로 반전)를 모두 하나의 사인 파동에서 계산합니다.
- **D**: 루버마다 `cos φ`로 투영 높이와 앞/뒷면 색을, `sin φ`로 옆면 두께를 정합니다. 바닥 그림자는 `ctx.transform`으로 창 좌표를 바닥 평면에 기울여 사영한 다음, 같은 루버 함수로 다시 그립니다.
- **E**: 격자마다 높이값을 계산하고 marching squares로 세 단계 색면을 그립니다. 색면은 단계별로 한 경로에 모아 한 번에 fill하므로 셀 사이 이음새가 생기지 않습니다. 등고선 16단계를 그 위에 그립니다. 제목 주변은 미리 계산한 마스크로 깊게 눌러 둡니다.

## 컨트롤
- 화면 하단 중앙의 `시안` 바: ← / A–E / → / 일시정지·재생. 현재 키·이름과 재생 상태(재생 중·일시정지·정지 화면)를 표시합니다.
- URL `?variant=A`–`E`. 새로고침해도 같은 시안이 유지되고, 선택은 `history.pushState`로 바꾸며(전체 새로고침 없음) 뒤로가기도 지원합니다.
- 키보드 ← → 로 시안을 바꿉니다(input/textarea/select/contenteditable에 포커스가 있으면 무시). 시안은 자동으로 넘어가지 않습니다.

## 수명주기
- 시간 `t`는 gsap ticker의 delta를 50ms 상한으로 잘라 **재생 중일 때만** 누적합니다. 일시정지했다가 다시 재생해도 화면이 튀지 않습니다.
- 사용자 일시정지 · 탭 숨김 · 히어로가 화면 밖에 있을 때 · reduced-motion이면 ticker 콜백을 떼어 내므로 모든 레이어가 멈춥니다(CSS 애니메이션이나 패럴랙스는 없음). 사용자 일시정지는 시안을 바꿔도 유지됩니다.
- 시안을 바꾸면 캔버스를 새로 만들어 교체합니다. 시안 모듈에는 리스너나 타이머가 없고 ticker는 하나만 씁니다. 크기 변경은 ResizeObserver로 감지해 DPR(최대 2)에 맞춰 다시 재고 곧바로 다시 그립니다.
- `prefers-reduced-motion: reduce`이면 `t = 4.2`초 시점의 정지 화면을 보여 줍니다. 아래 소개와 글 섹션은 애니메이션 없이 항상 보입니다.
- gsap `matchMedia` 콜백은 모든 DOM 참조와 상태를 초기화한 다음에 등록합니다.
