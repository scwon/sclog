# 타이포 구도 5안 — 정지 시안

`/type-posters/?variant=A` … `E`, `?view=all` (전체 보기). URL 끝 슬래시 필요(상대 경로 asset).
정적 HTML/CSS/JS + 인라인 SVG. 빌드·의존성·애니메이션 없음. 좌우 화살표 키, 하단 A–E, 이전/다음, 브라우저 히스토리 지원.

색: coral `#E9AC9F`, paper `#FAF8F5`, ink `#242424`만 사용. 그라디언트·그림자·입체 없음.
서명 `원성철`은 각 포스터에 작은 주석으로만 들어감.

공통 원칙: 배경 효과 + 손대지 않은 제목 구성이 아님. 글자를 지우면 구도도 함께 사라지도록 짰다.

---

## A 교차 (Crossing) — 1:1, 커스텀 벡터 레터링

- **구조**: 가로로 `scwon’s`, 세로로 `blog`를 크로스워드처럼 짜서 두 단어가 **o 하나를 공유**한다. 교차 칸만 coral 사각형이고, 나머지는 종이 위 잉크 획이다.
- **글자**: 140 단위 셀 위에 그린 기하 모노라인 글자(`#g-*`, 획 26)다. 열의 맨 위인 b의 어센더는 셀 위로, 맨 아래인 g의 디센더는 셀 아래로 뻗는다. 열 중간의 l은 b와 o를 잇는 순수한 수직 획이다. 아포스트로피는 coral 쐐기로 따로 그렸다.
- **의존성**: 십자형 실루엣 자체가 두 단어의 교차다. 크로스워드 번호 1·2가 가로/세로 읽기 방향을 조용히 알려 준다.
- **모션 후보(미정)**: 공유하는 o를 기준으로 가로·세로 글자의 간격과 획이 동시에 변하며 교차 구도를 유지한다.

## B 속공간 (Nested Counters) — 3:2, 커스텀 면 레터링 + 재사용 글리프

- **구조**: 화면을 꽉 채운 잉크 `blog`. b·l 어센더는 위로, g 고리는 아래로 화면 밖에 걸쳐 잘린다. b·o·g 세 개의 속공간만 coral로 채우고, 그 안에 `sc` / `wo` / `n’s`를 넣었다.
- **글자**: blog는 원(R210/r115)과 직사각형 스템(95)으로 짠 기하 면 글자다. 스템 폭이 링 두께와 정확히 같다. 속공간의 글자는 A의 획 글리프를 0.62배로 재사용했다.
- **의존성**: scwon’s는 blog의 빈 공간 속에서만 존재하고, blog의 속공간은 scwon’s를 담기 위해 존재한다. o 안에 o가 들어간다.
- **모션 후보(미정)**: blog의 속공간과 그 안의 글자가 함께 늘어나고 줄어들며 두 크기의 글자 관계를 유지한다.

## C 겹인쇄 (Overprint) — 1000×640, 실제 SVG 텍스트 변형

- **구조**: 세리프 볼드 이탤릭 두 줄이다. `scwon’s`(잉크)와 훨씬 큰 `blog`(coral)를 같은 폭 880으로 양끝 맞춤하고, 음수 행간으로 겹쳤다. b·l 어센더가 윗줄을 관통하고, **겹친 면은 마스크로 종이색이 빠진다(XOR)**.
- **글자**: `textLength` + `lengthAdjust="spacingAndGlyphs"`로 폰트 폴백(Georgia → Times → Noto Serif)이 달라도 폭과 맞물림 위치를 고정한다. 글자 높이는 폰트에 따라 약간 달라질 수 있다.
- **의존성**: 구도는 두 줄 글자의 교집합으로만 생긴다. 녹아웃 모양은 글자끼리 겹친 모양이므로 배경 장식이 될 수 없다.
- **모션 후보**: 두 줄의 행간이 벌어졌다 좁혀지며 녹아웃 면이 생겼다 사라진다.

## D 타일 (Tile Block) — 900×987, 커스텀 사각 모듈 레터링

- **구조**: `scw` / `on’s` / `blog` 세 줄이 같은 폭으로 늘어나 화면 전체를 빈틈없이 덮는다. 줄마다 확대율이 달라(2.68 → 2.26 → 2.01) 획 두께가 위에서 아래로 단계적으로 가늘어진다.
- **글자**: 100×130 박스에 획 30, 모서리 반경 20인 사각 모듈 글자(`#d-*`)다. 획 끝이 박스 가장자리까지 뻗어 칸을 꽉 채운다. 칸마다 바탕/글자가 ink↔paper↔coral로 뒤집힌다(figure/ground). 아포스트로피는 좁은 잉크 칸 위의 coral 쐐기다.
- **의존성**: 블록 자체가 글자의 집합이라서, 글자를 빼면 색 타일만 남아 의미가 없다.
- **모션 후보(미정)**: 여러 글자의 획과 칸 비율이 동시에 변하면서 전체 타일 구도를 유지한다.

## E 한 줄 (One Line) — 16:10, 커스텀 모노라인

- **구조**: 왼쪽 가장자리에서 들어온 하나의 글줄(baseline)이 `scwon’s`를 싣고 오른쪽에서 U턴한 뒤, 아랫줄 `blog`를 싣고 다시 왼쪽 밖으로 나간다. U턴 안쪽 반원만 coral 면이다. 펜을 떼는 유일한 표시인 아포스트로피도 coral이다.
- **글자**: 반지름 80, 획 24의 둥근 끝 기하 모노라인이다. 모든 글자가 글줄에 접하거나 글줄에서 서 있다(o는 접선, n·b·l 스템은 글줄 위, g는 글줄을 뚫고 내려감). 두 줄의 o와 n/g가 세로로 정렬된다.
- **의존성**: U자 선은 글줄이고, 글자 없이 남으면 그냥 선 하나다.
- **모션 후보(미정)**: 연결된 글줄과 글자의 곡률이 함께 변한다. 모든 글자가 보이는 한 구도를 유지한다.

## 파일

- `index.html`: 공유 글리프 스프라이트 + 포스터 5개(인라인 SVG) + 하단 컨트롤
- `styles.css`: 레이아웃(헤더 / 포스터 / 컨트롤 3단 그리드, SVG는 viewBox meet로 축소)
- `app.js`: `?variant=` 라우팅, pushState/popstate, 키보드 좌우, 전체 보기

## 확인 상태

제작 후 Chromium에서 1440×900, 390×844의 다섯 시안을 렌더링해 확인했다. 가로 넘침과 JavaScript 오류는 없었다. 가로형 시안은 모바일에서 비율을 유지해 축소된다. C의 시스템 폰트에 따른 형태 차이는 남아 있다. 모션은 구현하지 않았으며, 구도 선정 후 별도로 설계한다.
