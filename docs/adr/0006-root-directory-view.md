# 홈은 루트 디렉터리 뷰이고 흐름 로그는 폴더 안 파일이다

글이 두 폴더(`posts`, `ai-written`)로 나뉜 뒤(ADR 0005) 홈이 한 폴더의 흐름 로그 `posts.log`인 것이 어색해졌다. 탐색기는 루트 폴더 둘을 보이는데 에디터의 홈은 그중 하나만 쌓고, AI 글은 홈 맨 아래 칸으로만 드러났다. 폴더 화면(`/blog/`, `/ai-written/`)도 흐름 로그를 되풀이해 "이 폴더에 무엇이 있는가"를 보여 주지 못했다.

그래서 홈을 루트 디렉터리 뷰 `/`로 바꾼다. 블로그 이름·주석 아래 폴더 줄 `posts/ ---- 글 N편`, `ai-written/ ---- 글 M편`만 둔다. 폴더를 열면 그 폴더의 디렉터리 뷰가 열려 `tags/` 줄, 흐름 로그 파일 줄, 글 파일 줄(최신순)을 보인다. 흐름 로그는 없애지 않고 폴더 안 파일로 둔다: `posts/posts.log`(`/blog/posts.log/`), `ai-written/ai-written.log`(`/ai-written/ai-written.log/`). 홈 아래 AI 글 칸은 없어진다. 루트의 `ai-written/` 줄이 그 역할을 한다. 용어는 `GLOSSARY.md`의 루트·디렉터리 뷰·파일 줄·흐름 로그를 따른다.

## Considered Options

- **홈 탭 이름만 `root`로 바꾸고 내용은 흐름 로그로 둔다**: 바꿀 것이 적지만 "루트"라는 이름과 한 폴더의 로그라는 내용이 맞지 않는다. 폴더 화면도 그대로 되풀이다.
- **흐름 로그를 없애고 디렉터리 뷰만 둔다**: 구조가 가장 단순하지만 장 흐름을 접고 펴는 화면(DESIGN.md의 확정 방향)을 버리게 된다. 파일로 남기면 IDE 비유 안에서 자연스럽고 코드도 그대로다.
- **디렉터리 뷰 안을 연도 폴더로 나누고 연도 페이지를 둔다**: 탐색기와 같은 모양이지만 한 해에 글이 몇 편 안 되어 한 층이 더 생기는 값어치가 없다. 평평한 최신순으로 둔다.
- **루트에 최신 글 미리보기나 `tags/` 줄을 더 둔다**: 첫 화면이 복잡해진다. 폴더 두 줄로 끝낸다.

## Consequences

- 주소는 `/blog/`·`/ai-written/`가 그대로이고 모양만 디렉터리 뷰로 바뀐다. 흐름 로그만 새 주소(`/blog/posts.log/`, `/ai-written/ai-written.log/`)를 얻는다. 옛 `/`는 루트이므로 리디렉션은 없다.
- 파일 종류에 `root`와 `dir`이 생긴다. 패널은 루트에서 프로필, 글에서 탐색기이고, 디렉터리 뷰와 로그는 지금 화면을 둔다.
- 경로 표시줄의 폴더 조각(`posts`·`ai-written`)은 그 폴더의 디렉터리 뷰로 간다. 글 끝 이동 줄은 다음 파일 → 폴더 → 로그 → 맨 위로다.
- 폴더를 하나 더 두면 폴더 표(`FOLDER_ROUTES`)의 `dir`·`log` 한 줄로 루트 줄·디렉터리 뷰·로그 주소가 따라온다.
- 홈에서 글을 열려면 폴더 한 번을 더 거친다. QA 이동 시나리오도 루트 → `posts/` → 글로 시작한다.
