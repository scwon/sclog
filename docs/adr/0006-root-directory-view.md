# 홈은 루트 디렉터리 뷰이고 폴더 화면은 그 폴더의 흐름 로그다

글이 두 폴더(`posts`, `ai-written`)로 나뉜 뒤(ADR 0005) 홈이 한 폴더의 흐름 로그 `posts.log`인 것이 어색해졌다. 탐색기는 루트 폴더 둘을 보이는데 에디터의 홈은 그중 하나만 쌓고, AI 글은 홈 맨 아래 칸으로만 드러났다.

그래서 홈을 루트 디렉터리 뷰 `/`로 바꾼다. 블로그 이름·주석 아래 폴더 줄 `posts/ ---- 글 N편`, `ai-written/ ---- 글 M편`만 둔다. 폴더를 열면(`/blog/`, `/ai-written/`) 그 폴더의 흐름 로그가 폴더 이름(`posts/`)으로 열린다. 지금의 `posts.log` 내용이 그대로 `posts/`가 되는 것이고, `posts.log`·`ai-written.log`라는 이름과 홈 아래 AI 글 칸은 없어진다. 탐색기 트리는 에디터와 같은 단계를 보인다: 루트 폴더 머리(폴더 화면 링크) 아래 글 파일을 연도 없이 새 글 먼저 평평하게 둔다. 용어는 `GLOSSARY.md`의 루트·폴더 화면·흐름 로그·루트 폴더를 따른다.

## Considered Options

- **홈 탭 이름만 `root`로 바꾸고 내용은 흐름 로그로 둔다**: 바꿀 것이 적지만 "루트"라는 이름과 한 폴더의 로그라는 내용이 맞지 않는다.
- **폴더 화면을 파일 목록(디렉터리 뷰)으로 만들고 흐름 로그는 폴더 안 `posts.log` 파일로 둔다**: 처음 구현했던 모양이다. 홈 → 폴더 → 로그 → 글로 한 단계가 더 생겨 깊었고, `tags/`·`posts.log` 줄이 글보다 먼저 와 폴더 화면이 로그처럼 읽히지 않았다. 되돌렸다.
- **탐색기에 연도 폴더를 그대로 둔다**: 에디터는 연도로 나누지 않는데 탐색기만 연도로 나뉘어 단계가 어긋난다. 한 해에 글이 몇 편 안 되어 연도 층의 값어치도 없다.
- **루트에 최신 글 미리보기나 `tags/` 줄을 더 둔다**: 첫 화면이 복잡해진다. 폴더 두 줄로 끝낸다.

## Consequences

- 주소는 `/blog/`·`/ai-written/`가 그대로이고 탭·경로 표시줄 이름이 `posts/`·`ai-written/`로 바뀐다. 옛 `/`는 루트이므로 리디렉션은 없다.
- 파일 종류에 `root`와 `dir`이 생기고 `log`는 없어진다. 패널은 루트에서 프로필, 글에서 탐색기이고, 폴더 화면은 지금 화면을 둔다.
- 경로 표시줄의 폴더 조각(`posts`·`ai-written`)과 글 끝 이동 줄(다음 파일 → 폴더 → 맨 위로)은 폴더 화면으로 간다. 글의 파일 경로 `posts/<연도>/<슬러그>.mdx`는 그대로라 경로 표시줄에는 연도 조각이 남는다.
- 다음 파일은 같은 루트 폴더 안에서 연도를 넘어 이어진다. 전에는 연도 폴더를 넘지 않았다.
- 폴더를 하나 더 두면 폴더 표(`FOLDER_ROUTES`)의 `dir` 한 줄로 루트 줄·탐색기 구역·폴더 화면이 따라온다.
