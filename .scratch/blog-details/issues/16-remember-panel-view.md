# 16: 마지막 패널 화면 기억

**What to build:** 새로고침해도 패널이 마지막으로 고른 화면을 보인다. 기억은 브라우저 세션 동안만 남는다. 파일 종류에 따른 화면 규칙(홈은 프로필, 글은 탐색기, 그 밖은 지금 화면)은 그대로이고 저장된 화면은 그 규칙의 "지금 화면" 자리에 들어간다. 패널 화면 목록은 티켓 18이 검색 화면을 더할 수 있게 셋 이상을 받는 모양이 된다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

참고: 스펙 [블로그 디테일 1차](../spec.md) "패널: 세 화면과 마지막 화면", 결정 [기억 원칙](03-memory-principles.md), ADR 0004.

- [ ] `sessionStorage`의 `panel` 키에 `{ "v": 1, "view": "<화면>" }`을 저장한다. 열림·닫힘은 저장하지 않는다
- [ ] 저장값을 읽는 순수 함수가 `v`가 틀리거나 모르는 화면이면 버린다. 저장소를 쓸 수 없으면 안내 없이 메모리에만 둔다
- [ ] 서버 HTML은 지금처럼 파일 종류로 그리고 하이드레이션 뒤 저장된 화면에 파일 종류 규칙을 적용한 화면으로 바꾼다
- [ ] 개요로 가는 동작(`[data-explorer-toggle]`)은 늘 탐색기를 연다
- [ ] 단위 테스트: 저장값 복원(정상, `v` 틀림, 모르는 화면), 복원한 화면에 파일 종류 규칙 적용
- [ ] 프로필 패널 스펙의 Out of Scope "마지막 패널 화면을 새로고침 뒤에도 기억하기"에 이 티켓과 ADR 0004로 바뀌었다는 한 줄을 단다
- [ ] `pnpm qa` 이동 시나리오: 태그 화면에서 프로필을 고르고 새로고침하면 프로필이 남는다
- [ ] `pnpm verify`·`pnpm qa` 통과
