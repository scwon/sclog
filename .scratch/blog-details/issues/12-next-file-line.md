# 12: 다음 파일 줄

**What to build:** 글 끝 댓글 앞의 이동 줄이 흐름 로그의 링크 줄 모양으로 바뀐다. 맨 위에 다음 파일 줄(`newer-post.mdx →` + 글 제목)이 오고 그 아래에 `posts.log`와 `맨 위로`가 놓인다. 다음 파일은 탐색기에서 같은 폴더 안 바로 다음으로 새 글 하나다. 없으면 그 줄만 그리지 않는다. 줄 전체가 빌드 때 HTML로 나와서 JS 없이도 동작한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

참고: 스펙 [블로그 디테일 1차](../spec.md) "다음 파일", 결정 [다음 파일 열기](10-next-file.md).

- [ ] 다음 파일을 정하는 순수 함수가 있다. 탐색기 트리와 지금 글 URL을 받아 같은 폴더의 바로 다음 새 글을 돌려주고 없으면 `null`을 돌려준다. 폴더를 넘지 않는다. 창 틀(티켓 22의 팔레트 명령)도 쓸 수 있게 디자인 시스템 쪽에 둔다
- [ ] 단위 테스트: 같은 폴더의 다음 새 글, 폴더의 가장 새 글은 `null`, 글 한 편뿐일 때 `null`
- [ ] 글 끝 줄은 흐름 로그 링크 줄과 같은 모양이고 순서는 다음 파일 → `posts.log` → `맨 위로`다. 제목이 길면 한 줄에서 말줄임한다. 좁은 화면도 같은 모양이다
- [ ] 다음 파일 줄은 스크린 리더에 "다음 파일: {제목}"으로 읽힌다
- [ ] 다음 파일 줄의 메모 뒤에 꼬리표를 덧붙일 자리가 있다(티켓 20이 채운다)
- [ ] 빌드 결과물 테스트: 폴더의 가장 새 글이 아니면 다음 파일 줄이 있고 가장 새 글이면 없다. `posts.log`·`맨 위로` 줄은 늘 있다
- [ ] 시험용 글은 테스트 고정값으로만 만들고 `src/content`에 넣지 않는다
- [ ] `pnpm verify` 통과, `pnpm qa`의 글 화면 접근성 검사 통과
