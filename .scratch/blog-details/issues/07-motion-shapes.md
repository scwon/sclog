# 07: 움직임 디테일의 모양

**Type:** prototype

**Blocked by:** 02, 06

**Status:** resolved

지도: [블로그 디테일 1차](../map.md)

## Question

[1차 묶음](06-first-bundle.md)에 남은 움직임 디테일(탭 닫힘, 테마 퍼짐, 흐름 로그 커서 깜빡임)은 각각 어떤 모양과 길이로 움직이는가? 화면 전환 이어지기는 묶음에서 빠졌다.

- 디테일마다 변형 두세 개를 실제 창 틀 위에서 비교한다
- 기존 모션 토큰으로 되는지, 새 토큰이 필요한지
- 움직임 줄이기 설정에서의 대체 동작

- 탭을 닫거나 열 때 활성 탭이 탭 줄 밖에 있으면 화면 안으로 스크롤한다(탭 넘침 처리에서 옮겨 온 조건). 스크롤도 움직임 줄이기 설정을 따른다
- 기존 펼침이 글 본문 블록에도 걸려 있다(움직임 연구에서 확인). 지도의 "글 본문은 정적" 제약을 펼침에도 적용할지, 펼침은 예외로 둘지 정한다
- Safari에서 창 틀이 옮겨질 때 탭 애니메이션이 다시 도는지 확인한다(움직임 연구의 미확인 위험)

## Answer

비교에 쓴 변형은 브랜치 `prototype/motion-shapes`(커밋 `9273c19`)에 있다. 개발 서버에서 `?tab=&theme=&cursor=&unfold=`로 고를 수 있다.

| 디테일 | 정한 모양 | 시간·이징 | 움직임 줄이기 |
| --- | --- | --- | --- |
| 탭 닫힘 | 움직임 없이 바로 닫는다. 접힘·떨어짐 변형은 어색해서 버렸다 | 없음 | 해당 없음 |
| 탭 등장 | 지금처럼 탭이 새로 생길 때만 왼쪽에서 펼쳐진다(`animate-unroll`). 닫았던 글을 다시 열면 새 탭이므로 다시 펼쳐진다 | `--motion-enter`, `--motion-easing` | 바로 나타남(지금 그대로) |
| 테마 퍼짐 | 테마 버튼 가운데에서 새 테마가 원형으로 퍼진다. 별도 `document.startViewTransition`으로 그리고 키프레임은 CSS에 둔다 | `--motion-slow`, `--motion-easing` | 바로 바뀜 |
| 커서 깜빡임 | 지금 모양(1.1초, `steps(1)`, 계속 깜빡임)을 그대로 둔다. 다만 1.1초를 새 토큰 `--motion-blink`로 옮긴다 | `--motion-blink`(새 토큰) | 깜빡이지 않음(지금 그대로) |
| 펼침 | 탭이 새로 생겨 그 파일이 처음 보일 때만 펼친다. 아래 규칙 참고 | 지금 토큰 그대로 | 펼치지 않음(지금 그대로) |

**펼침 규칙**: 펼침은 그 파일의 탭이 새로 생겨 처음 보일 때만 일어난다. 프로토타입에서 처음 열기 → 다른 탭 → 돌아오기 → 닫기 → 다시 열기 순서로 확인했다(펼침 / 펼침 / 없음 / 없음 / 펼침).
- 열려 있는 탭으로 돌아가는 경우(탭을 누르거나 뒤로·앞으로 이동)에는 펼치지 않고 바로 보인다.
- 탭을 닫았다가 같은 글을 다시 열면 새 탭이므로 다시 펼친다. 세션에서 이미 연 적이 있어도 마찬가지다.
- `posts.log`는 닫을 수 없는 탭이라 세션에서 처음 보일 때 한 번만 펼친다.
- 새로고침하면 탭이 그대로 남아 있으므로 펼치지 않는다.
- "처음 보인 탭" 목록은 탭과 수명이 같다. `sessionStorage`에 두고, 탭을 닫으면 목록에서 뺀다. 구현할 때는 탭 스토어(`tabs`) 항목에 함께 두는 편이 자연스럽다. 프로토타입은 따로 키를 썼다.

**글 본문과 펼침**: 펼침은 파일을 열 때 한 번만 일어나는 움직임이라 본문 블록도 그대로 펼친다. 본문을 빼 보니 머리 부분만 펼쳐지고 본문은 한 번에 나타나 따로 노는 것처럼 보였다. 지도의 제약을 "본문은 읽는 동안 정적이다. 파일을 처음 열 때의 펼침은 예외"로 고쳤다.

**활성 탭 스크롤**: 활성 탭이 탭 줄 밖에 있으면 `scrollIntoView({ inline: 'nearest' })`로 화면 안에 들인다. 움직임 줄이기 설정에서는 부드러운 스크롤 없이 바로 옮긴다.

**테마 퍼짐 구현 조건**(움직임 연구에서 이어짐)
- `<html>`에 `transition:name="root"`를 더한다. 덮어쓰는 규칙은 CSS 레이어 밖에 둔다.
- 라우터 이동 중(`astro:before-preparation`부터 `astro:page-load`까지), 움직임 줄이기 설정, `startViewTransition`이 없는 브라우저에서는 퍼짐 없이 바로 바꾼다.
- 클릭 좌표와 반지름은 `<html>`의 사용자 정의 속성으로 넘기고, 끝나면 지운다.

**Safari**: `moveBefore()`가 없는 브라우저에서는 창 틀이 옮겨질 때 그 안에서 돌던 CSS 애니메이션이 처음부터 다시 돈다. Chromium에서 `moveBefore()`를 지워 흉내 내 보았지만 ego가 그리는 속도가 느려 재시작 여부를 측정하지 못했다. 대신 이번 결정으로 이동하는 동안 창 틀에서 도는 애니메이션이 없어졌다. 탭 닫힘에는 움직임이 없고, 탭 등장은 이동이 끝난 뒤(`astro:page-load`) 시작하며, 테마 퍼짐은 이동 중에 시작하지 않는다. 그래서 따로 막을 일은 없다. 실제 Safari 확인은 구현 뒤 QA에서 한다.

**토큰**: 새 토큰은 `--motion-blink` 하나다. 나머지는 기존 모션 토큰으로 충분하다.
