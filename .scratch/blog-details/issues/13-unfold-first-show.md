# 13: 펼침은 처음 보일 때만

**What to build:** 에디터 펼침이 그 파일의 탭이 새로 생겨 처음 보일 때만 일어난다. 이미 열린 탭으로 돌아가거나(탭 클릭, 뒤로·앞으로) 새로고침할 때는 내용이 바로 보인다. 닫았던 글을 다시 열면 새 탭이라 다시 펼쳐진다. `posts.log`는 세션에서 처음 보일 때 한 번 펼쳐진다. 탭을 열거나 닫은 뒤 활성 탭이 탭 줄 밖에 있으면 화면 안으로 들어온다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

참고: 스펙 [블로그 디테일 1차](../spec.md) "펼침과 탭", 결정 [움직임 디테일의 모양](07-motion-shapes.md). 모양 비교는 브랜치 `prototype/motion-shapes`(`9273c19`).

- [ ] 탭 스토어 항목에 "처음 보임" 표시가 있다. 표시는 탭과 수명이 같다(닫으면 사라지고 새로고침하면 남는다). 표시가 없는 이전 형식 저장값은 처음 보인 것으로 친다
- [ ] 연 파일로 다음 탭 상태와 펼칠지 여부를 정하는 순수 함수가 있고 레이아웃의 펼침 스크립트는 그 결과만 따른다
- [ ] 단위 테스트: 처음 열기 → 다른 탭 → 돌아오기 → 닫기 → 다시 열기가 펼침/펼침/없음/없음/펼침이다. `posts.log`는 한 번만 펼친다. 복원한 탭(새로고침)은 펼치지 않는다. 이전 형식 저장값도 덮는다
- [ ] 탭 등장(`animate-unroll`)은 지금 그대로다. 탭 닫힘에는 움직임이 없다
- [ ] 활성 탭이 탭 줄 밖에 있으면 `scrollIntoView({ inline: 'nearest', block: 'nearest' })`로 들인다. 움직임 줄이기 설정에서는 `behavior: 'auto'`다
- [ ] `pnpm qa` 이동 시나리오에 위 다섯 단계 순서를 더하고 에디터 루트의 펼침 표시 유무로 확인한다
- [ ] `pnpm verify`·`pnpm qa` 통과
