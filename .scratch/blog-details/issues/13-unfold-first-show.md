# 13: 펼침은 처음 보일 때만

**What to build:** 에디터 펼침이 그 파일의 탭이 새로 생겨 처음 보일 때만 일어난다. 이미 열린 탭으로 돌아가거나(탭 클릭, 뒤로·앞으로) 새로고침할 때는 내용이 바로 보인다. 닫았던 글을 다시 열면 새 탭이라 다시 펼쳐진다. `posts.log`는 세션에서 처음 보일 때 한 번 펼쳐진다. 탭을 열거나 닫은 뒤 활성 탭이 탭 줄 밖에 있으면 화면 안으로 들어온다.

**Blocked by:** None (can start immediately)

**Status:** done

참고: 스펙 [블로그 디테일 1차](../spec.md) "펼침과 탭", 결정 [움직임 디테일의 모양](07-motion-shapes.md). 모양 비교는 브랜치 `prototype/motion-shapes`(`9273c19`).

- [x] 탭 스토어 항목에 "처음 보임" 표시가 있다. 표시는 탭과 수명이 같다(닫으면 사라지고 새로고침하면 남는다). 표시가 없는 이전 형식 저장값은 처음 보인 것으로 친다
- [x] 연 파일로 다음 탭 상태와 펼칠지 여부를 정하는 순수 함수가 있고 레이아웃의 펼침 스크립트는 그 결과만 따른다
- [x] 단위 테스트: 처음 열기 → 다른 탭 → 돌아오기 → 닫기 → 다시 열기가 펼침/펼침/없음/없음/펼침이다. `posts.log`는 한 번만 펼친다. 복원한 탭(새로고침)은 펼치지 않는다. 이전 형식 저장값도 덮는다
- [x] 탭 등장(`animate-unroll`)은 지금 그대로다. 탭 닫힘에는 움직임이 없다
- [x] 활성 탭이 탭 줄 밖에 있으면 `scrollIntoView({ inline: 'nearest', block: 'nearest' })`로 들인다. 움직임 줄이기 설정에서는 `behavior: 'auto'`다
- [x] `pnpm qa` 이동 시나리오에 위 다섯 단계 순서를 더하고 에디터 루트의 펼침 표시 유무로 확인한다
- [x] `pnpm verify`·`pnpm qa` 통과

## Comments

### 2026-10-27 구현 (브랜치 `blog-details/13-unfold-first-show`)

**결정**

- 탭 스토어 항목은 `TabEntry`(`TabFile` + `shown`)다. `$openTabs`의 값도 이 모양이다. 판정은 `tabs.logic.ts`의 순수 함수 `show(state, file) → { state, unfold }`가 맡고, 바인딩 `showTab(file)`이 결과를 저장한 뒤 `unfold`만 돌려준다. 레이아웃의 펼침 스크립트는 `astro:page-load`에서 에디터 루트의 `data-file-*`로 `showTab`을 불러 `true`일 때만 펼친다.
- 창 틀(`Shell`)도 같은 `page-load`에서 `openTab`으로 탭을 연다. 두 리스너의 순서는 첫 로드와 이후 이동에서 다를 수 있다. 그래서 `openTab`(`addOrActivate`)은 새 탭을 `shown: false`로 열기만 하고, 표시는 `show`에서만 붙인다. 어느 쪽이 먼저 불려도 판정이 같다.
- 움직임 줄이기 설정에서도 `showTab`은 부른다. 표시는 남기고 펼치지만 않는다. 설정을 끈 뒤 같은 탭으로 돌아와도 펼치지 않게 하려는 것이다.
- 복원: 표시가 없는 항목(이전 형식)은 이미 보인 것으로 친다. `posts.log`는 저장값의 `posts.log` 항목에서 표시를 읽는다. 이전 형식도 `posts.log`를 첫 칸에 저장했으므로 기존 방문자는 펼침이 다시 일어나지 않는다. 저장값에 `posts.log` 항목이 없으면 아직 보이지 않은 것으로 둔다.
- 활성 탭 스크롤은 `Tabs`의 `useActiveTabInView`다. 탭 목록이나 활성 탭이 바뀐 뒤 활성 탭이 탭 줄 사각형 밖으로 나가 있을 때만 `scrollIntoView`를 부른다. 하이드레이션 직후 복원한 활성 탭이 밖에 있을 때도 들인다. 390px에서 탭 다섯 개로 맨 끝 새 탭과 `posts.log` 복귀를 ego-browser로 확인했다.
- QA 이동 시나리오: 글이 한 편뿐이라 글에 달린 태그 화면 두 개를 새 파일로 쓴다. 펼침 표시는 애니메이션이 끝나면 걷히므로 `<html>`에 `MutationObserver`를 달아 `data-unfold`가 붙는 순간의 파일 URL을 모은다. 홈·열린 글로 가기, 처음 열기, 다른 탭, 탭으로 돌아오기, 뒤로, 앞으로, 닫기, 다시 열기를 확인한다. 4313 포트 미리보기에서 `nav.mjs`를 직접 돌려 모두 통과했다. `pnpm qa`(4399 포트)는 통합 브랜치에서 돌린다.
- `pnpm verify`는 통과했다. 마지막 체크박스는 `pnpm qa`를 통합 브랜치에서 돌린 뒤 체크한다.
