# 06: 1차 묶음 고르기

**Type:** grilling

**Blocked by:** 01, 02

**Status:** resolved

지도: [블로그 디테일 1차](../map.md)

## Question

남은 후보 가운데 무엇을 1차 묶음에 넣는가?

- 후보: 탭 닫힘 움직임, 화면 전환 이어지기, 테마 퍼짐, 흐름 로그 커서 깜빡임, 줄 번호 클릭, 장 제목 앵커, 탭 가운데 클릭·우클릭 메뉴, 탐색기 hover 미리보기, 경로 표시줄 장 드롭다운, 다음 파일 열기, 탭 넘침 처리, 404 제안, 단축키(체계는 [단축키 체계](04-shortcut-scheme.md)에서 정함, ⌘P·⌘B·⌘⇧F), 외부 링크 표시, 읽은 글 표시, 이어 읽기, 마지막 패널 화면 기억, 패널 너비 드래그·기억, 검색(패널·명령 팔레트)
- 기준: 독자 편의와 첫인상을 반반 섞는다. 크기는 `/to-tickets` 결과가 티켓 10개 안팎이다.
- 연구 결과(검색 방법, 움직임과 ClientRouter)에서 드러난 비용을 반영한다.
- 기억 디테일의 저장 방식은 [기억 원칙](03-memory-principles.md)이 정했다. "탭 유지"는 거기서 범위 밖이 됐다.

빠진 후보는 지도의 Out of scope에 이유와 함께 적는다. 남은 후보 가운데 동작이 아직 정해지지 않은 것은 새 티켓으로 만든다.

## Answer

글이 여러 편 쌓인다는 전제로 골랐다. 지금 공개된 글이 1편이라는 사실은 판단에 넣지 않았다. 묶음은 디테일 열한 개이고, 독자 편의 쪽 일곱과 첫인상 쪽 다섯이 섞여 있다(명령 팔레트는 양쪽에 걸친다). `/to-tickets`로 나누면 티켓 11개 안팎이 된다.

| 디테일 | 쪽 | 동작이 정해진 곳 |
| --- | --- | --- |
| 검색 화면 + 빌드 때 만드는 색인 | 편의 | [검색 방법](01-search-options.md), [검색 화면과 팔레트](05-search-panel-and-palette.md) |
| 명령 팔레트 + 단축키(⌘P·⌘B·⌘⇧F) | 첫인상 | [단축키 체계](04-shortcut-scheme.md), [검색 화면과 팔레트](05-search-panel-and-palette.md) |
| 이어 읽기 | 편의 | 저장은 [기억 원칙](03-memory-principles.md), 겉모습은 [이어 읽기와 읽은 글의 겉모습](08-resume-and-read-marks.md) |
| 읽은 글 표시 | 편의 | 위와 같음 |
| 마지막 패널 화면 기억 | 편의 | [기억 원칙](03-memory-principles.md) |
| 다음 파일 열기 | 편의 | [다음 파일 열기](10-next-file.md) |
| 외부 링크 표시 | 편의 | 이 답(아래) |
| 줄 번호 클릭 | 첫인상 | [줄 번호 클릭의 동작](09-line-number-click.md) |
| 탭 닫힘 움직임 → 처음 열 때만 펼침 | 첫인상 | [움직임 디테일의 모양](07-motion-shapes.md)에서 탭 닫힘에는 움직임을 두지 않기로 하고, 대신 펼침이 처음 열 때만 일어나게 바꿨다 |
| 테마 퍼짐 | 첫인상 | 위와 같음 |
| 흐름 로그 커서 깜빡임 | 첫인상 | 위와 같음 |

**외부 링크 표시**: 본문 링크 가운데 다른 도메인으로 가는 링크에만 붙인다. 링크 글자 뒤에 창 틀의 GitHub 링크와 같은 ↗(`ExternalIcon`)를 붙이고, 스크린 리더에는 숨은 글자 "(외부 링크)"를 읽힌다. 열기는 같은 탭에서 하며 `target="_blank"`를 강제하지 않는다. 표시는 빌드 때 HTML에 넣으므로 JS가 꺼져 있어도 보인다.

**합친 것**: 장 제목 앵커 복사는 줄 번호 클릭에 합쳤다. 장 제목 줄의 번호를 누르면 그 장의 주소가 복사되기 때문이다.

**뺀 것**은 지도의 Out of scope에 이유와 함께 적었다. 화면 전환 이어지기, 탭 가운데 클릭·우클릭 메뉴, 경로 표시줄 장 드롭다운, 404 비슷한 파일 제안, 탐색기 hover 미리보기, 탭 넘침 처리, 패널 너비 드래그·기억이 여기에 든다. 탭 넘침에서는 "활성 탭을 화면 안으로 스크롤한다"는 조건 하나만 [움직임 디테일의 모양](07-motion-shapes.md)으로 옮겼다.
