# 22: 명령 목록과 ⌘⇧F

**What to build:** 팔레트에 `>`를 치면 명령 목록과 단축키가 나온다. 이 목록이 이 블로그의 단축키 도움말이다. 명령으로 검색·패널 화면·테마·다음 파일·읽기 기록 지우기를 실행한다. ⌘⇧F(Ctrl+Shift+F)는 패널 검색 화면을 열고 입력창에 포커스를 준다. 마우스를 쓰는 독자는 활동 막대 툴팁에서 키를 본다.

**Blocked by:** 12 (다음 파일 줄), 18 (패널 검색 화면), 19 (단축키와 팔레트로 파일 열기), 20 (읽기 기록과 읽은 글 꼬리표)

**Status:** ready-for-agent

참고: 스펙 [블로그 디테일 1차](../spec.md) "명령 팔레트"·"단축키", 결정 [단축키 체계](04-shortcut-scheme.md)·[패널 검색 화면과 명령 팔레트의 모양](05-search-panel-and-palette.md)·[다음 파일 열기](10-next-file.md).

- [ ] 입력이 `>`로 시작하면 명령 모드다. 명령은 아래 순서이고 `>` 뒤 글자로 파일 모드와 같은 방식으로 거른다. 키가 없는 명령은 키 칸을 비운다

| 명령 | 키 | 보이는 때 |
| --- | --- | --- |
| 파일 열기 | ⌘P | 늘 |
| 본문에서 찾기 | ⌘⇧F | 늘 |
| 패널 열고 닫기 | ⌘B | 늘 |
| 탐색기 보기 | | 늘 |
| 프로필 보기 | | 늘 |
| 테마 전환 | | 늘 |
| 다음 파일 열기 | | 지금 글에 다음 파일이 있을 때 |
| 읽기 기록 지우기 | | 늘 |

- [ ] `다음 파일 열기`는 티켓 12의 다음 파일 함수로 정한다. `테마 전환`은 테마 버튼에서 퍼진다(티켓 14가 끝났다면). `읽기 기록 지우기`는 프로필 칸과 같은 동작이다
- [ ] 키 판정 함수에 ⌘⇧F를 더한다. 검색 화면을 열고 입력창에 포커스를 준다. 티켓 19의 겹침 확인표에서 받을 수 없는 조합이 나왔다면 ⌘⇧F를 빼고 목록과 안내 문구에서도 지운다
- [ ] 입력창 안내 문구는 "파일 이름으로 찾기 · > 를 입력하면 명령"이다. 키 표기와 안내의 키 부분은 `(hover: hover) and (pointer: fine)`일 때만 보인다. 표기는 플랫폼에 따라 `⌘⇧F`/`Ctrl+Shift+F`다
- [ ] 툴팁: 검색 아이콘 `검색 (⌘⇧F)`, 탐색기 아이콘 `탐색기 (⌘B)`. 프로필 아이콘에는 키가 없다
- [ ] 단위 테스트: 명령 모드 전환과 거르기, `다음 파일 열기`가 다음 파일이 있을 때만 들어감, 플랫폼별 키 표기, ⌘⇧F 판정(입력창·조합 중 꺼짐 포함)
- [ ] `pnpm qa`: ⌘⇧F로 검색 화면이 열리고 입력창에 포커스가 간다. `>` 명령 목록이 보이는 팔레트를 axe에 넣는다
- [ ] `pnpm verify`·`pnpm qa` 통과
