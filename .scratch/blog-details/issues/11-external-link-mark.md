# 11: 외부 링크 표시

**What to build:** 글 본문에서 다른 도메인으로 가는 링크 뒤에 ↗가 붙고 스크린 리더는 링크를 "(외부 링크)"와 함께 읽는다. 표시는 빌드 때 HTML에 들어가므로 JS가 꺼져 있어도 보인다. 링크는 지금처럼 같은 탭에서 열린다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

참고: 스펙 [블로그 디테일 1차](../spec.md) "외부 링크", 결정 [1차 묶음 고르기](06-first-bundle.md).

- [ ] 외부 링크 판정이 순수 함수로 있다. `http(s)`이면서 호스트가 사이트 호스트와 다를 때만 참이다(`www.` 유무는 같은 호스트로 본다). 상대 주소·해시·`mailto:`는 거짓이다. 단위 테스트가 이 다섯 경우를 덮는다
- [ ] 빌드의 MDX 처리에 rehype 단계가 더해져, 외부 링크 글자 뒤에 창 틀 GitHub 링크와 같은 ↗ SVG(`aria-hidden`)와 숨은 글자 "(외부 링크)"를 넣는다
- [ ] 마지막 낱말과 ↗ 사이에서 줄이 바뀌지 않는다
- [ ] `target="_blank"`를 넣지 않고 링크에 이미 있던 속성은 그대로 둔다
- [ ] 창 틀 안 링크(프로필 연락처 등)는 대상이 아니다
- [ ] 빌드 결과물 테스트: 본문의 외부 링크에는 아이콘과 숨은 글자가 있고 `target="_blank"`가 없다. 같은 사이트 링크에는 표시가 없다
- [ ] `pnpm verify` 통과
