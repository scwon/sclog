# 10: 다음 파일 열기

**Type:** grilling

지도: [블로그 디테일 1차](../map.md)

## Question

글 끝에서 권하는 "다음 파일"은 무엇이고, 어디에 어떤 모양으로 두는가? 글이 여러 편 쌓인다는 전제로 정한다([1차 묶음](06-first-bundle.md)).

- 무엇이 다음인가: 시간순으로 다음(또는 이전) 글인지, 같은 태그의 글인지, 둘 다인지. 다음 글이 없을 때는 무엇을 보이는가
- 읽은 글은 건너뛰는가([이어 읽기와 읽은 글의 겉모습](08-resume-and-read-marks.md)과 맞춘다)
- 글 끝 어디에 두는가: 흐름 로그의 링크 줄 모양인지, 꼬리(댓글) 앞인지 뒤인지
- 단축키를 붙이는가. [단축키 체계](04-shortcut-scheme.md)의 기준(VS Code에 대응하는 키가 있고 브라우저 키와 겹치지 않을 것)을 따른다
- JS 없이도 보이는 정적 링크로 만드는가
