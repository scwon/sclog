# 20: 읽기 기록과 읽은 글 꼬리표

**What to build:** 독자가 글을 끝까지(읽은 비율 90% 이상) 읽으면 읽은 글이 되고 중간에 떠나면 마지막 장과 비율이 남는다. 탐색기·홈 흐름 로그·다음 파일 줄에 읽은 글은 `✓`, 읽는 중인 글은 `42%`로 표시된다. 프로필 화면 맨 아래 "읽기 기록" 칸에서 기록 수를 보고 한 번에 지운다. 지우면 표시가 바로 사라진다. 기록은 다음 방문까지 남는다.

**Blocked by:** 12 (다음 파일 줄)

**Status:** ready-for-agent

참고: 스펙 [블로그 디테일 1차](../spec.md) "읽기 기록과 이어 읽기", 결정 [기억 원칙](03-memory-principles.md)·[이어 읽기와 읽은 글의 겉모습](08-resume-and-read-marks.md), ADR 0004. 모양은 브랜치 `prototype/resume-and-read-marks`(`?reading=A`).

- [ ] `localStorage`의 `read`(`{ v: 1, urls }`)와 `position`(`{ v: 1, entries: { url, chapter, percent }[] }`, 최근 갱신 순, 최대 20편)에 저장한다
- [ ] 기록 순수 모듈: 90% 이상이면 `read`에 넣고 `position`에서 뺀다. 90% 미만이고 지금 장이 있으면 `position`을 갱신해 맨 앞으로 올린다. 장이 없으면(첫 장 제목 전) 저장하지 않는다. 20편을 넘으면 가장 오래된 것부터 버린다. 복원 때 모양이 틀린 값, 발행 글 목록에 없는 URL, 읽은 글의 위치를 버린다. `N편 읽음 · M편 읽는 중`을 집계한다
- [ ] 단위 테스트가 위 규칙을 모두 덮는다
- [ ] 기록 스토어는 디자인 시스템에 있고 창 틀과 페이지 스크립트가 같이 구독한다. 저장소에는 초당 한 번 이하로 묶어 쓰고 화면을 떠날 때(`astro:before-swap`, `pagehide`) 마지막 값을 쓴다. 저장소를 못 쓰면 안내 없이 메모리에만 둔다. `storage` 이벤트는 구독하지 않는다
- [ ] 탐색기 파일 줄 끝 꼬리표: 읽은 글은 `✓`이고 파일 이름이 흐려진다. 읽는 중은 `42%`(강조 글자색)다. 파일 이름이 먼저 말줄임된다
- [ ] 흐름 로그 글 로그 줄 머리에 `✓ 읽음`·`71% 읽는 중`을, 다음 파일 줄 메모 뒤에 같은 꼬리표를 HTML이 그려진 뒤 덧붙인다
- [ ] 스크린 리더 글자는 "읽음"·"42% 읽는 중"이고 기호는 `aria-hidden`이다
- [ ] 프로필 화면 맨 아래 "읽기 기록" 칸에 `이 브라우저에 N편 읽음 · M편 읽는 중`과 `기록 지우기`가 있다. 기록이 없으면 `이 브라우저에 남은 읽기 기록이 없습니다`만 보이고 버튼은 그리지 않는다. 지우기는 두 키를 모두 지우고 확인 창을 띄우지 않는다
- [ ] `pnpm qa`: 글 끝까지 스크롤하면 탐색기에 `✓`가 붙고 지우기를 누르면 사라진다. 꼬리표가 붙은 탐색기와 프로필의 읽기 기록 칸을 axe에 넣는다
- [ ] `Shell` Storybook에 꼬리표가 붙은 탐색기와 읽기 기록 칸 스토리가 있다
- [ ] `pnpm verify`·`pnpm qa` 통과
