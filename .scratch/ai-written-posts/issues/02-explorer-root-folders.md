# 02: 탐색기의 루트 폴더

**What to build:** 탐색기 최상위가 `posts`와 `ai-written` 두 구역으로 나뉘고, 각 구역 안은 지금처럼 연도 폴더와 파일 줄이다. AI 글이 한 편도 없으면 `ai-written` 구역이 없다. 다음 파일은 같은 연도 폴더 안에서만 이어져 루트를 넘지 않고, 명령 팔레트는 두 루트의 파일을 모두 연다.

**Blocked by:** 01 (폴더가 있는 글 모델과 AI 글 화면)

**Status:** ready-for-agent

스펙의 "탐색기 트리"를 따른다.

- [ ] 트리의 최상위가 루트 폴더(이름 + 연도 폴더 목록)이고 `posts`가 먼저, `ai-written`이 다음이다. AI 글 0편이면 `ai-written` 루트가 없다
- [ ] 창 틀이 두 폴더의 발행 글로 트리를 만들고, 탐색기가 루트마다 이름 있는 구역을 그린다(지금 `posts` 구역 머리와 같은 모양)
- [ ] 다음 파일이 루트를 넘지 않는다. AI 글의 다음 파일은 AI 글이다
- [ ] 명령 팔레트 파일 목록에 두 루트의 파일이 모두 있고 줄의 경로로 루트가 보인다
- [ ] Shell 로직 테스트: 루트 두 개 트리로 `nextFile`·`paletteFiles`(선례 `tree.test.ts`·`palette.test.ts`)
- [ ] Storybook: 탐색기가 두 루트를 그리는 스토리 하나
- [ ] `pnpm verify` 통과
