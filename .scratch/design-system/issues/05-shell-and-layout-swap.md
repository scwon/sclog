# 05: 창 틀 `Shell`을 올리고 모든 페이지를 IDE 창 안으로 옮긴다

**What to build:** 홈·글·태그·404 모든 주소가 전체 화면 IDE 창(제목 표시줄·활동 막대·탐색기 트리·탭·경로 표시줄·코랄 상태줄)으로 열리고, 링크로 이동할 때 창 틀은 그대로 남고 에디터 내용만 바뀐다. 글을 열면 탭이 추가되고 상태줄에 2초 열기 요약이 나온다. 에디터 안의 내용은 아직 옛 마크업이어도 된다(06·07이 바꾼다).

**Blocked by:** 02 (글꼴), 03 (테마 스토어·원자), 04 (탭 스토어·Tabs)

**Status:** ready-for-agent

참고: 스펙 "3층" `Shell`·페이지 ↔ 창 틀 계약·반응형, ADR 0001(아일랜드 하나, `transition:persist`), DESIGN.md "전체 화면 IDE와 파일 열기 로그" 표(창 치수·반응형·탭·파일 열기 로그), 시안 `ide.css` title bar/activity bar/sidebar/status bar/responsive 절, `app.js` 라우터·탐색기·상태줄 부분.

- [ ] `Shell` 컴포넌트가 제목 표시줄(블로그 이름의 코랄 아포스트로피, 창 제목, 원성철, GitHub, `ThemeToggle`)·활동 막대·탐색기(글 트리 `posts/<연도>/<파일>.mdx`, 글 페이지에서는 그 아래 개요 영역)·`Tabs`·상태줄을 `position: fixed`로 그린다. 모든 치수는 창 치수 토큰에서 온다
- [ ] 레이아웃이 `<ClientRouter />`를 쓰고 `Shell`을 `client:load transition:persist`로 올린다. 에디터 내용은 아일랜드 밖 정적 HTML이며 창 치수 토큰만큼 여백을 둬 고정 요소와 겹치지 않는다
- [ ] 에디터 루트가 `data-file-*` 속성(제목, 경로, URL, 용량, 읽는 시간)을 갖고, `Shell`은 `astro:page-load`마다 이를 읽어 탭 스토어에 추가·활성화하고 상태줄에 `❯ open <경로>` → `✓ 열림 · <용량> · 읽는 시간 <N>분`을 약 2초 보인 뒤 원래 상태로 돌아간다. 홈은 `posts.log`가 활성
- [ ] 탐색기 트리 데이터는 빌드 시 글 컬렉션에서 만들어 props로 넘긴다. 현재 글은 트리에서 강조된다
- [ ] 1100px 미만: 탐색기는 활동 막대 버튼으로 여는 겹침 패널(가림막 포함, Esc로 닫힘). 760px 미만: 활동 막대 대신 제목 표시줄 메뉴로 여는 서랍, 경로 표시줄에 `개요` 버튼
- [ ] 태그 페이지와 404도 같은 창 안 에디터로 열리고 탭 제목이 각각 `tags/…`, `404`다. 글 페이지의 댓글 등 기존 기능은 에디터 안에 그대로 있다
- [ ] 키보드만으로 창 틀의 모든 버튼·탭·링크에 닿고 포커스 외곽선이 보인다. 건너뛰기 링크가 에디터로 간다
- [ ] 빌드 결과물 테스트에 "모든 HTML에 `data-file-url`이 있고 그 값이 파일 경로와 일치, 글 URL 변경 없음" 검사가 추가된다
- [ ] `Shell` 스토리(홈 상태·글 열림 상태)가 두 테마에서 a11y 위반 없이 렌더링된다
- [ ] `CI=1`로 `pnpm lint`, `pnpm format:check`, `pnpm build`, `pnpm test`, `pnpm build-storybook` 통과
