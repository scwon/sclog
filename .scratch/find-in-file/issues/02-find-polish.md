# 02: 찾기 줄 다듬기와 팔레트 명령

**What to build:** 에디터에서 글자를 고른 채 ⌘F를 누르면 그 글자가 검색어로 들어간다. ⌘G·⇧⌘G(Ctrl+G·Ctrl+Shift+G)로 찾기 줄 밖에서도 다음·이전 일치로 간다. 다른 파일로 옮기면 찾기 줄이 닫히고, 다시 ⌘F를 누르면 마지막 검색어가 들어 있다. 팔레트 `>` 목록에 `이 파일에서 찾기 ⌘F`가 생긴다.

**Blocked by:** 01 (⌘F 찾기 줄)

**Status:** ready-for-agent

참고: 스펙 [파일에서 찾기](../spec.md) "키"·"찾기 줄"·"화면 이동과 기억"·"명령 팔레트".

- [ ] 열 때 에디터 안에서 고른 글자가 한 줄이면 검색어로 넣는다. 없으면 마지막 검색어를 넣고 모두 선택한다
- [ ] `SHORTCUT_KEYS`에 ⌘G·⇧⌘G가 있고 판정이 다음·이전 동작을 돌려준다. 찾기 줄이 닫혀 있으면 마지막 검색어로 열고 이동한다. 마지막 검색어가 없으면 찾기 줄만 연다. 지원하지 않는 브라우저에서는 `null`이다. 단위 테스트가 덮는다
- [ ] `astro:before-swap`에서 찾기 줄을 닫고 칠한 것을 지운다. 마지막 검색어는 창 틀 메모리에만 남고 새로고침하면 비워진다
- [ ] 창 틀 명령 `find-in-file`이 `ShellCommand`에 있고 `runCommand`가 실행한다. 팔레트 명령 목록에서 `파일 열기` 바로 다음에 `이 파일에서 찾기 ⌘F`가 있다. 지원하지 않는 브라우저에서는 빠진다. 단위 테스트가 자리와 키 칸을 본다
- [ ] `docs/agents/shortcuts.md`의 지금 붙은 키·겹침 확인표에 ⌘G·⇧⌘G를 더한다. 블로그 디테일 1차 스펙 Comments에 이 스펙이 스토리 35를 대신한다는 한 줄을 남긴다
- [ ] `pnpm qa`: 찾기 줄을 열어 검색어를 넣고 다른 글·화면으로 옮기면 닫히고, 다시 ⌘F를 누르면 마지막 검색어가 들어 있다. 찾기 줄 밖에서 ⌘G로 다음 일치로 간다
- [ ] `pnpm verify`·`pnpm qa` 통과
