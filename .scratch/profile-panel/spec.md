# 패널의 프로필 화면

Status: done

용어는 `GLOSSARY.md`(패널·탐색기·프로필·활동 막대)를 따른다. 예전 프로필 코드는 `eab6761^`의 `src/components/ProfileSection.astro`·`src/data/profile.ts`에 있다.

## Problem Statement

티켓 06에서 홈을 흐름 로그로 바꾸며 예전 프로필(사진·이름·소개·링크)을 지웠다. 지금은 제목 표시줄의 작성자 이름과 GitHub 링크가 블로그 주인을 알리는 전부이고, 좁은 화면에서는 그마저 숨는다.

## Solution

활동 막대 맨 아래에 프로필 아이콘을 두고, 누르면 패널이 탐색기 대신 프로필 화면을 보여 준다. 패널은 한 번에 한 화면만 보여 준다.

## Decisions

1. **프로필 화면 내용**: 사진(`/images/scwon_pt.jpg`), 이름, 직함(Frontend Developer), 소개 2~3문장, 경력 한 줄(`WhaTapLabs · 2017.10~`), 링크(GitHub·LinkedIn·이메일). 소개 문구는 사람이 쓴다. 구현은 예전 문구 "프론트엔드 개발자 원성철입니다."를 자리 표시로 둔다. 제목 표시줄과 이름·GitHub가 겹쳐도 그대로 둔다.
2. **사진 뒤집기**: 사진에 마우스를 올리거나 사진을 누르면 동전처럼 Y축으로 뒤집혀 도트 사진이 보인다. 회전은 CSS가 하고, 누르기(탭·키보드)는 사진 버튼의 눌림 상태로 뒤집힌 채 둔다. `prefers-reduced-motion`에서는 돌지 않고 바로 바뀐다. 속도 감지 스핀 이스터에그는 넣지 않는다.
3. **프로필 아이콘**: 탐색기·소스 아이콘과 같은 선 굵기의 사람 모양 SVG. 활동 막대 맨 아래에 두고, 선택 표시(코랄 세로 막대)와 hover 색은 탐색기 아이콘과 같다.
4. **화면 전환 규칙 (VS Code와 같음)**:
   - 다른 화면의 아이콘을 누르면 그 화면으로 바뀐다(패널이 닫혀 있으면 열면서).
   - 지금 화면의 아이콘을 다시 누르면 패널이 닫힌다.
   - 마지막 화면은 화면 이동 사이에 유지된다(창 틀이 남으므로). 새로고침하면 탐색기로 돌아간다. 저장소(localStorage)는 쓰지 않는다.
   - 상태줄 등에서 개요로 가는 동작(`[data-explorer-toggle]`)은 항상 탐색기 화면으로 바꿔 연다.
5. **좁은 화면(760px 미만)**: 활동 막대가 숨으므로, 겹침 패널 맨 위의 "탐색기" 제목 줄을 `탐색기 | 프로필` 두 버튼으로 바꿔 화면을 고른다. 제목 표시줄의 메뉴 버튼은 지금처럼 패널을 연다.
6. **데이터 위치**: 프로필 내용은 `src/site.ts`의 `SITE` 옆 `PROFILE`에 둔다. 이름·GitHub 주소처럼 `SITE`에 이미 있는 값은 다시 적지 않고 가리킨다. `Shell`은 직렬화 가능한 `profile` prop으로 받는다. 디자인 시스템은 블로그 내용을 모른다(ADR 0002).

## Done When

- 넓은 화면·좁은 화면 모두에서 위 전환 규칙대로 탐색기와 프로필을 오간다.
- `Shell` Storybook에 프로필 화면이 보이는 스토리가 있다.
- `pnpm verify`와 `pnpm qa`가 통과한다.

## Comments

- 사진은 원본(2.8MB·2MB)을 240px 정사각형으로 잘라 `public/images/profile/`에 두었다(약 21KB·73KB). 원본은 그대로 둔다.
- 탭으로 뒤집기는 CSS만으로는 iOS에서 보장되지 않아, 사진을 `aria-pressed` 버튼으로 만들었다(결정 2 수정).
- 패널 이름을 용어에 맞춰 `#explorer` → `#panel`, `<html data-explorer>` → `<html data-panel>`로 바꿨다. 개요 버튼의 `data-explorer-toggle`은 탐색기 화면을 여는 버튼이라 그대로 둔다.
- `pnpm qa`: axe에 홈의 프로필 화면(세 폭 × 두 테마)을 더했고, 이동 시나리오에 프로필 → 이동 뒤 유지 → 탐색기 복귀를 더했다. 테마 버튼 선택자는 `header button[aria-pressed]`로 좁혔다(패널 버튼도 `aria-pressed`를 쓴다).
- 접근성 이름: 제목 표시줄 메뉴 버튼은 패널을 열고 닫으므로 "탐색기" → "패널"로 바꿨다. 활동 막대 버튼은 화면을 고르는 토글이라 `aria-expanded` 대신 `aria-pressed`를 쓰고, 패널의 `aria-label`은 지금 화면 이름을 따른다.
- 좁은 화면의 `탐색기 | 프로필` 버튼은 탭처럼 화면만 고르고, 지금 화면을 다시 눌러도 닫지 않는다(결정 5). 닫기는 메뉴 버튼·가림막·Esc가 맡는다.
- 경력은 줄 목록(`career: string[]`)으로 받는다. 지금은 한 줄이다.
