# 02: 복사 토스트

**What to build:** 선택 툴바에서 복사하면 화면 아래 가운데에 "복사했어요" 토스트가 약 2초 떴다 사라지고 스크린 리더에도 알린다. 클립보드가 막히면 ⌘C를 쓰라는 안내 토스트가 뜬다. 버튼의 체크 아이콘은 그대로 둔다. 토스트는 디자인 시스템 부품이라 나중에 다른 동작도 쓴다.
